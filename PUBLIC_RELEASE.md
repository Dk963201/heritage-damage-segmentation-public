# Public research snapshot

This distribution starts with fresh Git history. Student identifiers, personal contact details, private assignment links, and named supervisor references have been removed from the distributed project documents. Report author metadata and Git commit identity use the project name. The GitHub owner username remains visible.

Original experiment scores, model weights, reviewed masks, candidate provenance, and photographer/license credits are preserved. Historical reports are labeled as historical, not as completed target-domain research. Public source photographs retain their source attribution and may contain source-supplied photographic metadata; they are not the maintainer's personal photo collection.

The original working repository and its old history remain private. This is a focused privacy cleanup of the distributed snapshot, not a security certification or a guarantee that a GitHub account is anonymous.

See docs/INSTALL.md for setup, docs/ASSETS.md for separate downloads, and docs/IMPROVING_RESULTS.md for the evidence still needed.
